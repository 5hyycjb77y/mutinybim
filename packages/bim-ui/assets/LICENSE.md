MutinyBIM source-code license. Forks and redistributions must replace them
with their own marks unless they have written permission.

| File | What it is |
| --- | --- |
| `mutiny-logo.jpg` | Original artwork as provided (1024×1024) |
| `mutiny-logo.png` | Same, lossless |
| `mutiny-scene.png` | Illustration without the wordmark (splash art) |
| `mutiny-wordmark.png` | Raster crop of the wordmark from the artwork |
| `mutiny-wordmark.svg` | Clean vector wordmark, hand-built slab geometry (no font outlines; `currentColor`) |
| `mutiny-icon.svg` | Vector icon mark (the thrown crate), palette colors |
| `mutiny-icon-{32,64,192,512}.png` | Raster icon crops from the artwork |

The vector wordmark is drawn from rectangles, arcs and polygons in
`src/wordmark-paths.ts`, so no third-party font license applies.
