# MutinyBIM user guide

This guide is for the people who use the app: contractors, designers and
engineers. It covers the hosted app at `https://app.mutinybim.com`. If you
run your own copy, use your own address wherever this guide says
`https://app.mutinybim.com`.

For building, running or extending MutinyBIM, see the developer docs in
[`docs/`](../) and the [project README](../../README.md).

| Page | What it covers |
| --- | --- |
| [Getting started](getting-started.md) | Making an account, My models, opening and sharing a model, Settings and Ask AI. |
| [A tour of the editor](editor-tour.md) | The Building Model editor: views, levels, placing, routing and sizing, spaces, schedules, notes, sheets, branches and versions. |
| [Connect Claude or another assistant](connect-claude.md) | Connecting Claude, ChatGPT and other assistants to your models, approvals, running an example script, and tool families. |
